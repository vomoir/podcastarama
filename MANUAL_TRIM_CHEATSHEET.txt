⚡ 5-STEP WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Open Audio Editor
  → Episode list → Click ✨ Edit Audio

STEP 2: Play & Listen
  → Click ▶️ Play
  → Listen for when intro music ends (speech begins)
  → Listen for when speech ends (outro begins)

STEP 3: Identify Exact Times
  → Note the time when intro ends
  → Note the time when outro starts
  → Example: Intro ends at 0:30, Outro starts at 45:25

STEP 4: Set Manual Trim Boundaries
  
  Keep from (seconds):  [30.0]
  Keep until (seconds): [2725.0]
  
  (0:30 = 30 seconds, 45:25 = 2725 seconds)

STEP 5: Apply Trim
  → Click "Apply Trim"
  → Wait for ✅ "Trimmed! New duration: MM:SS"
  → Done! Backup created automatically

🕐 TIME CONVERSIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Quick formula: MM:SS = (MM × 60) + SS

Examples:
  0:30  = 30 seconds
  1:00  = 60 seconds
  5:00  = 300 seconds
  10:00 = 600 seconds
  30:00 = 1800 seconds
  45:25 = 2725 seconds (45 × 60 + 25)
  60:00 = 3600 seconds (1 hour)

Or just paste the time into a calculator!

📊 HOW TO USE THE WAVEFORM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Visual Guide:
  
  Dense purple bars    = Audio with sound (speech)
  Thin/missing bars    = Quiet audio (silence)
  Very thin            = Intro/outro songs often
  
  ┌──────────────────────────────────────────┐
  │ [Thin] [DENSE DENSE] [Thin]              │  Waveform
  │  intro     content     outro              │
  └──────────────────────────────────────────┘
   ^                              ^
   Start keeping here (intro ends)
                                  Stop keeping here (outro starts)

💾 BACKUP & RESTORE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every trim creates automatic backup:
  ✅ Original file saved
  ✅ Trimmed version replaces episode audio
  ✅ Can restore anytime with 1 click

To restore:
  → Open Audio Editor for the episode
  → Scroll to "Restore Backup"
  → Click "Restore Backup"
  → Done! Back to original

⚠️  Only latest backup kept. Delete after restore.

🔍 DEBUGGING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Audio won't play?
  → Press F12 to open DevTools
  → Go to Console tab
  → Look for [AudioEditor] messages
  → Share error messages with developer

Trim failed?
  → Verify: Keep from < Keep until
  → Verify: Both times within total duration
  → Check file permissions on server
  → Check `/tmp/backend.log` for errors

Times confusing?
  → Use the MM:SS display below each field
  → Or calculator: MM × 60 = total seconds
